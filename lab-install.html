สรุปสำหรับผู้ดูแล

  • ติดตั้ง 5 โปรแกรม: Node.js LTS, Git for Windows, VS Code, ZCode และเบราว์เซอร์ Chrome หรือ Edge — ฟรีทั้งหมด ไม่มีค่า license
  • เปิด HTTPS ขาออก (พอร์ต 443) ไปยังโดเมนในข้อ 4 และไม่บล็อก localhost พอร์ต 8976 และ 8787
  • ผู้เรียนไม่ต้องมีสิทธิ์ administrator — ทุกคำสั่งในวันอบรมติดตั้งลงโฟลเดอร์ผู้ใช้หรือโฟลเดอร์โปรเจกต์
  • ไม่ต้องติดตั้ง wrangler, Python, Docker หรือฐานข้อมูลใด ๆ — wrangler ติดตั้งเองในแต่ละโปรเจกต์ผ่าน npm
  • ตรวจรับด้วยสคริปต์ check-lab.ps1 (ข้อ 5) ทุกเครื่องต้องขึ้น “พร้อมใช้”

2. วิธีติดตั้ง

เลือกทางใดทางหนึ่ง ทำบนเครื่องต้นแบบ 1 เครื่องก่อน ตรวจรับให้ผ่าน (ข้อ 5) แล้วจึงโคลน image หรือกระจายไปทุกเครื่อง

ทาง A — winget (แนะนำ)

เปิด PowerShell แบบ Run as administrator แล้วรัน:

winget install --id OpenJS.NodeJS.LTS -e --silent --scope machine --accept-package-agreements --accept-source-agreements
winget install --id Git.Git -e --silent --scope machine --accept-package-agreements --accept-source-agreements
winget install --id Microsoft.VisualStudioCode -e --silent --scope machine --accept-package-agreements --accept-source-agreements --override "/VERYSILENT /NORESTART /MERGETASKS=!runcode,addcontextmenufiles,addcontextmenufolders,addtopath"
winget install --id ZhipuAI.ZCode -e --silent --scope machine --accept-package-agreements --accept-source-agreements
winget install --id Google.Chrome -e --silent --scope machine --accept-package-agreements --accept-source-agreements
  • --scope machine ทำให้ติดตั้งให้ผู้ใช้ทุกคนบนเครื่อง (สำคัญกับ VS Code ซึ่งค่าเริ่มต้นของ winget เป็นแบบติดตั้งรายผู้ใช้)
  • ถ้า ZCode ไม่รองรับ --scope machine ให้ตัดตัวเลือกนี้ออกเฉพาะบรรทัด ZCode แล้วตรวจว่าผู้ใช้อื่นบนเครื่องเปิดได้

3. ตั้งค่าหลังติดตั้ง

เรื่องทำอะไรเหตุผล
PATHเปิด terminal ใหม่ แล้ว node -v, git --version, code --version ต้องขึ้นเลขเวอร์ชันเอกสาร lab เรียกคำสั่งเหล่านี้ตรง ๆ
อุ่น npm cache (แนะนำ)รันคำสั่ง C3 ในข้อ 5.2 หนึ่งครั้งด้วยบัญชีผู้ใช้ที่ผู้เรียนจะใช้ ก่อนบันทึก imageทั้งห้องติดตั้งพร้อมกันตอน 10:00 — มี cache แล้วเร็วขึ้นมากและไม่แย่งแบนด์วิดท์
ระบบคืนค่าเครื่อง (Deep Freeze ฯลฯ)เปิดได้ แต่ต้องไม่รีสตาร์ทระหว่าง 09:00–16:00 หรือกำหนดไดรฟ์/โฟลเดอร์ที่ไม่ถูกคืนค่าให้เก็บงานงานของผู้เรียนอยู่บนเครื่องทั้งวัน
เบราว์เซอร์แนะนำปิดการบันทึกรหัสผ่านด้วย policy (PasswordManagerEnabled = false) · อนุญาต pop-up และการเปิด http://localhostเครื่องใช้ร่วมกัน · ล็อกอิน wrangler ส่งผลกลับมาที่ localhost
PowerShell execution policyไม่ต้องเปลี่ยนหลักสูตรใช้ Git Bash · ใน PowerShell ใช้ npx.cmd แทนได้
Antivirus / EDRต้องไม่ลบหรือบล็อก workerd.exe และ esbuild.exe ใน node_modules ของโฟลเดอร์ผู้ใช้เป็นตัวจำลอง Cloudflare บนเครื่อง (npm run dev)
บัญชีบนเครื่องอย่าล็อกอินบัญชีใดค้างไว้ใน ZCode, Cloudflare, Google หรือ ChatGPT ก่อนบันทึก imageผู้เรียนแต่ละคนใช้บัญชีของตัวเอง

5. ตรวจรับเครื่อง

5.1 สคริปต์ตรวจอัตโนมัติ — ทุกเครื่อง

ดาวน์โหลด check-lab.ps1 ไว้ในโฟลเดอร์ใดก็ได้ แล้วรันด้วยบัญชีผู้ใช้ที่ผู้เรียนจะใช้ (ไม่ต้องเป็น admin):

powershell -NoProfile -ExecutionPolicy Bypass -File check-lab.ps1

สคริปต์ตรวจ 20 ข้อ: เวอร์ชันของ Node/npm/Git/Git Bash/VS Code/ZCode · การเข้าถึงโดเมนในข้อ 4 · พอร์ต 8976 และ 8787 ว่าง · npm ดึงแพ็กเกจได้จริง · ไม่มีบัญชี Cloudflare ค้างบนเครื่อง · แล้วบันทึกผลเป็นไฟล์ check-lab-<ชื่อเครื่อง>.txt ไว้ข้างสคริปต์

✅ ผ่านเมื่อบรรทัดสุดท้ายขึ้น “พร้อมใช้ (PASS ทุกข้อ)” · ถ้าไม่ผ่าน ดูคอลัมน์ Detail ของข้อที่ FAIL

5.2 ทดสอบครบวงจร — เครื่องต้นแบบ 1 เครื่อง (ผู้สอนทำร่วมกับ IT)

เปิด Git Bash แล้วรันทีละบรรทัด:

cd ~
npm create cloudflare@latest my-app -- --template=werapango/workers-app-starter --no-deploy --no-git --no-agents
cd my-app
npm run dev

เปิด http://localhost:8787 ต้องเห็นหน้าแอป และ http://localhost:8787/api/health ตอบ "ok": true → กด Ctrl+C แล้วทดสอบล็อกอินและ deploy ด้วยบัญชีทดสอบของผู้สอน:

npx wrangler login
npx wrangler deploy
npx wrangler delete
npx wrangler logout
cd ~ && rm -rf my-app

✅ ผ่านเมื่อทุกคำสั่งทำงาน · เปิด URL *.workers.dev ที่ได้จาก deploy ได้ · login ไม่ค้างหลังกด Allow · และหลัง logout รัน check-lab.ps1 แล้วข้อ “no wrangler login” เป็น PASS

6. หลังจบการอบรม

ผู้เรียนได้รับคำแนะนำให้ออกจากระบบทุกบริการก่อนกลับ แต่เพื่อความปลอดภัยของบัญชีผู้เรียน ผู้ดูแลควรทำอย่างใดอย่างหนึ่ง:

  • คืนค่า image (ง่ายที่สุด) — หรือรีสตาร์ทถ้าใช้ระบบคืนค่าอัตโนมัติ
  • หรือทำความสะอาดเอง: ลบโฟลเดอร์ %USERPROFILE%\my-app (และโฟลเดอร์งานอื่นของผู้เรียน) · ลบ %APPDATA%\xdg.config\.wrangler (สิทธิ์ deploy ของ Cloudflare) · ออกจากระบบใน ZCode · ล้างข้อมูลเบราว์เซอร์ (cookie และรหัสผ่านที่บันทึก)

แล้วรัน check-lab.ps1 อีกครั้ง ข้อ “no wrangler login” ต้องเป็น PASS
