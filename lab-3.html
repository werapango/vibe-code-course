Release ขึ้น production (5 นาที)

🎯 ทำขั้นนี้เพื่ออะไร

production คือระบบที่ใช้งานจริงบน Cloudflare ที่ผู้ใช้เปิดผ่านอินเทอร์เน็ต ส่วน deploy คือการส่งโค้ดขึ้นไปที่นั่น ลำดับต้องเป็น สร้างตารางบน production (migration) ก่อน แล้วค่อย deploy ถ้าโค้ดใหม่ขึ้นไปก่อนที่ตารางจะมี ผู้ใช้จริงจะเจอ error no such table

รันใน Git Bash ทีละคำสั่ง (--remote หมายถึงฐานข้อมูลบนคลาวด์):

npx wrangler d1 migrations apply app-db --remote
npx wrangler deploy

คำสั่ง deploy จะแสดง URL ของแอปตอนจบ จากนั้นรัน smoke test กับ production โดยใช้บัญชี admin บน production ของคุณ (เปลี่ยน URL และรหัสในคำสั่งเป็นของตัวเอง):

npm run smoke url=https://my-app.ชื่อsubdomain.workers.dev user=admin pass=รหัสของคุณ

คำสั่งนี้ใช้ได้ทั้ง Git Bash และ PowerShell ไม่ต้องกังวลว่าข้อมูลทดสอบจะค้างอยู่ เพราะ smoke test สร้างรถและผู้ใช้ชั่วคราว แล้วลบทิ้งเองตอนจบ

✅ ผ่าน Lab 3 เมื่อ
  • npm run trace ✅ ตามรอยครบ (AC 33 ข้อ · FR 15 ข้อ)
  • smoke test กับ production ไม่มี ❌
  • จองรถจากมือถือบน URL จริงได้ 1 รายการ
  • git log มี commit แยกต่อ task
🆘 ถ้าตามไม่ทัน (เกิน 14:35)
