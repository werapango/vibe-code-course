Release ขึ้น production (5 นาที)

🎯 เจตนา

ลำดับต้องเป็น migration ก่อน แล้วค่อย deploy — ถ้าโค้ดใหม่ขึ้นไปก่อนตาราง ผู้ใช้จริงจะเจอ error no such table

npx wrangler d1 migrations apply app-db --remote
npx wrangler deploy

แล้วรัน smoke test กับ production ด้วยบัญชี admin บน production ของคุณ (เปลี่ยน URL และรหัสเป็นของตัวเอง):

BASE_URL=https://my-app.ชื่อsubdomain.workers.dev SMOKE_ADMIN_USER=admin SMOKE_ADMIN_PASS=รหัสของคุณ npm run smoke

PowerShell: $env:BASE_URL="https://..."; $env:SMOKE_ADMIN_USER="admin"; $env:SMOKE_ADMIN_PASS="..."; npm run smoke · smoke test สร้างรถ/ผู้ใช้ชั่วคราวแล้วลบทิ้งเองตอนจบ

✅ ผ่าน Lab 3 เมื่อ
  • npm run trace ✅ ตามรอยครบ (AC 33 ข้อ · FR 15 ข้อ)
  • smoke test กับ production ไม่มี ❌
  • จองรถจากมือถือบน URL จริงได้ 1 รายการ
  • git log มี commit แยกต่อ task
