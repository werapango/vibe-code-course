PART A — เตรียมเครื่อง Lab (ผู้สอน / IT)

📄 เอกสารฉบับเต็มสำหรับผู้ดูแลห้อง

คำสั่งติดตั้งแบบเงียบ (winget / msiexec), รายการเครือข่าย, สคริปต์ตรวจรับ check-lab.ps1 และใบตรวจรับรายเครื่องสำหรับพิมพ์ อยู่ที่ เอกสารติดตั้งซอฟต์แวร์ห้อง Lab

ผู้เรียนไม่ต้องทำส่วนนี้ — เป็นสเปกสำหรับผู้ดูแลห้อง Lab

A1. ซอฟต์แวร์ที่ต้องติดตั้งทุกเครื่อง

ซอฟต์แวร์เวอร์ชันใช้ทำอะไรหมายเหตุการติดตั้ง
Node.jsLTS (22 ขึ้นไป)รัน npm และ npx wranglerตัวติดตั้ง .msi จาก nodejs.org · ค่าเริ่มต้นทั้งหมด (รวม Add to PATH)
Git for Windowsล่าสุดบันทึกงานเป็นจุด ๆ (checkpoint) หลังทุก task และได้โปรแกรม Git Bash มาด้วยค่าเริ่มต้นทั้งหมด · คงตัวเลือก “Git Bash Here”
VS Codeล่าสุดอ่านโค้ดและ diffติ๊ก “Add to PATH” และ “Open with Code”
ZCodeล่าสุดAI coding agent (AI ที่อ่าน เขียน และแก้โค้ดในโปรเจกต์ให้)จากหน้าดาวน์โหลดของ Z.ai · ไม่ต้องล็อกอิน (ผู้เรียนล็อกอินบัญชีตัวเองวันอบรม)
เบราว์เซอร์ (Chrome / Edge)ล่าสุดทดสอบแอป + F12 ดู cookie · สมัคร/ล็อกอินบริการ–

ไม่ต้องติดตั้ง wrangler แยก — แต่ละโปรเจกต์ติดตั้งเองใน node_modules และเรียกผ่าน npx · curl มีใน Windows 10/11 อยู่แล้ว · ผู้เรียนไม่ต้องมีสิทธิ์ administrator ทุกคำสั่งในหลักสูตรติดตั้งลงโฟลเดอร์โปรเจกต์หรือโฟลเดอร์ผู้ใช้

A3. ทดสอบเครื่องต้นแบบ 1 เครื่อง

🎯 ทำขั้นนี้เพื่ออะไร

ยืนยันว่า image ของห้อง (ชุดระบบที่จะคัดลอกลงทุกเครื่อง) ใช้ได้จริงก่อนโคลนไปทุกเครื่อง — ทำด้วยบัญชีทดสอบของผู้สอน (ไม่ใช่บัญชีผู้เรียน)

เปิด Git Bash แล้วรันทีละบรรทัด:

node -v
git --version
code --version
npm create cloudflare@latest my-app -- --template=werapango/workers-app-starter --no-deploy --no-git --no-agents
cd my-app
npm run dev

เปิด http://localhost:8787 ต้องเห็นหน้า "แอปของฉัน" และ /api/health ตอบ "ok": true (ช่วงนี้ db เป็น "no-binding" เพราะยังไม่สร้างฐานข้อมูล — ถือว่าปกติ) จากนั้นกด Ctrl+C ใน Git Bash เพื่อหยุดเซิร์ฟเวอร์ แล้วทดสอบ login และ deploy ด้วยบัญชีทดสอบ:

npx wrangler login
npx wrangler deploy
npx wrangler delete
npx wrangler logout
✅ ผ่านเมื่อ

ทุกคำสั่งทำงานโดยไม่มี error, เปิด URL workers.dev ที่ได้จาก deploy ได้, login ไม่ค้างหลังกด Allow และหลัง logout คำสั่ง npx wrangler whoami บอกว่ายังไม่ได้ล็อกอิน

⚡ แนะนำ: เก็บแพ็กเกจไว้ล่วงหน้าใน npm cache

การรันคำสั่ง C3 ข้างบนหนึ่งครั้งบนเครื่องต้นแบบ ทำให้แพ็กเกจถูกเก็บใน npm cache ของ image วันอบรมทั้งห้องจะติดตั้งเร็วขึ้นและไม่แย่งแบนด์วิดท์พร้อมกัน (ถ้าเครื่องใช้ระบบคืนค่าอัตโนมัติ ให้ทำก่อนบันทึก image)

⚠ ถ้าเครื่องคืนค่าอัตโนมัติเมื่อรีสตาร์ท (Deep Freeze ฯลฯ)

งานของผู้เรียนจะหายเมื่อรีสตาร์ท — แจ้งผู้เรียนว่าห้ามรีสตาร์ทเครื่องระหว่างวัน หรือกำหนดโฟลเดอร์/ไดรฟ์ที่ไม่ถูกคืนค่าให้เก็บงาน (โค้ดที่ deploy แล้วยังอยู่บน Cloudflare แต่ซอร์สโค้ดอยู่บนเครื่อง)

PART B — สมัครบัญชี (ผู้เรียน)

ทำผ่านเว็บเบราว์เซอร์อย่างเดียว ไม่ต้องติดตั้งอะไร — ทำล่วงหน้าจากมือถือได้ เพื่อประหยัดเวลาช่วงเช้า ถ้ายังไม่ได้ทำ ทำบนเครื่อง Lab ตอน 09:00

B1. บัญชี Z.ai

🎯 ทำขั้นนี้เพื่ออะไร

บัญชี Z.ai ทำให้คุณได้โควต้าฟรีสำหรับใช้ ZCode (โมเดล GLM-5.3 ~3M token และ Flash ~5M token — token คือหน่วยนับข้อความที่ AI อ่านและเขียน, M = ล้าน) บัญชีเป็นของคุณเอง ส่วนโปรแกรม ZCode ติดตั้งไว้บนเครื่อง Lab แล้ว

  1. เปิดเว็บ z.ai ในเบราว์เซอร์ แล้วสมัครบัญชีด้วยอีเมลหรือบัญชี Google
  2. ถ้ามีอีเมลยืนยันส่งมา ให้เปิดอีเมลนั้นแล้วคลิกลิงก์ยืนยัน
✅ ผ่านเมื่อ

ล็อกอินเข้าเว็บ z.ai ได้ และเห็นว่าเป็นบัญชีของคุณ

🪙 อย่าเพิ่งใช้โควต้า

ไม่ต้องลองสั่งงานล่วงหน้า เก็บโควต้าไว้ใช้วันอบรม (คาดว่าทั้งวันใช้ประมาณ 0.4–0.7M token)

B2. บัญชี Cloudflare (Free)

บริการที่ใช้ โควตาฟรี และบริการที่ไม่ต้องกด: Cloudflare ที่ใช้ในหลักสูตร

🎯 ทำขั้นนี้เพื่ออะไร

แอปที่คุณสร้างวันนี้จะถูก deploy (นำขึ้นออนไลน์) ไปไว้ในบัญชีนี้ สมัครไว้ก่อนจะได้ไม่ต้องรอสมัครพร้อมกันทั้งห้อง และอีเมลยืนยันมีเวลาส่งมาถึง

  1. เปิด dash.cloudflare.com/sign-up แล้วกรอกอีเมลและตั้งรหัสผ่านเพื่อสมัคร
  2. ยืนยันอีเมล (คลิกลิงก์ในอีเมลที่ Cloudflare ส่งมา — ถ้ายังไม่ยืนยัน บางคำสั่งจะใช้ไม่ได้)
  3. ถ้ามีหน้าให้เลือกแผน ให้เลือก Free และถ้าถามว่าจะเพิ่มเว็บไซต์/โดเมน ให้ข้าม (เราใช้ที่อยู่เว็บฟรีแบบ workers.dev ไม่ต้องมีโดเมนของตัวเอง)
⚠ ถ้าหน้าจอขอบัตรเครดิต

หยุด ไม่ต้องกรอก กลับไปหน้า dashboard หลัก — การสมัครบัญชีและการใช้ Workers/D1 ไม่ต้องใช้บัตร

✅ ผ่านเมื่อ

เข้าหน้า dashboard ของ Cloudflare ได้ และยืนยันอีเมลแล้ว — จำอีเมลและรหัสผ่านไว้ใช้ล็อกอินบนเครื่อง Lab

B3. บัญชี Gemini หรือ ChatGPT (เลือกอย่างใดอย่างหนึ่ง)

🎯 ทำขั้นนี้เพื่ออะไร

ใช้ใน Lab 2 ให้ AI ช่วยร่างเอกสารความต้องการ (SRS) และการออกแบบผ่านหน้าเว็บ ใช้ฟรีและไม่กินโควต้า ZCode ซึ่งเราเก็บไว้เขียนโค้ดตอนบ่าย

  • Gemini: gemini.google.com ล็อกอินด้วยบัญชี Google
  • ChatGPT: chatgpt.com สมัครด้วยอีเมลหรือบัญชี Google
⚠ ใช้แผนฟรีเท่านั้น

ไม่ต้องสมัครแผนเสียเงินหรือกรอกบัตร · ห้ามใส่ข้อมูลส่วนตัวหรือข้อมูลจริงของหน่วยงานลงใน prompt — วันนี้ใช้แค่โจทย์สมมติของหลักสูตร

✅ ผ่านเมื่อ

เปิดหน้าแชตและพิมพ์ข้อความได้ — จำรหัสผ่านไว้ล็อกอินบนเครื่อง Lab

PART C — ตั้งค่าบนเครื่อง Lab เช้าวันอบรม (ผู้เรียน)

ทำช่วง 09:00–09:20 ผู้สอนจะเดินตรวจทีละเครื่อง

1

เปิด Git Bash

🎯 ทำขั้นนี้เพื่ออะไร

terminal คือหน้าต่างสำหรับพิมพ์คำสั่ง วันนี้เราพิมพ์คำสั่ง Cloudflare เองใน terminal ตลอดวัน และใช้ Git Bash เพราะคำสั่งในเอกสาร lab เขียนไว้สำหรับ Git Bash คัดลอกไปวางได้ทันทีโดยไม่ต้องแก้

กดปุ่ม Start ของ Windows พิมพ์ Git Bash แล้วกด Enter จะได้หน้าต่างที่มีคำว่า MINGW64 อยู่ในบรรทัดบน จากนั้นพิมพ์คำสั่งข้างล่างทีละบรรทัดแล้วกด Enter เพื่อตรวจว่าเครื่องมือครบ:

node -v
git --version
✅ ผ่านเมื่อ

คำสั่งแรกแสดงเวอร์ชัน Node ตั้งแต่ v22 ขึ้นไป และคำสั่งที่สองแสดงเลขเวอร์ชันของ Git (ถ้าไม่ขึ้น แจ้งผู้สอน — เป็นปัญหาของเครื่อง ไม่ใช่ของคุณ)

2

ล็อกอิน ZCode

🎯 ทำขั้นนี้เพื่ออะไร

ผูก ZCode บนเครื่องนี้กับบัญชี Z.ai ของคุณ เพื่อใช้โควต้าของตัวเอง

  1. เปิดโปรแกรม ZCode แล้วล็อกอินด้วยบัญชี Z.ai ของคุณ (ถ้าเห็นบัญชีคนอื่นค้างอยู่ ให้ออกจากระบบก่อน)
  2. มองหาที่เลือกโมเดล (อยู่ใต้ช่องพิมพ์ ต้องมีให้เลือกทั้ง GLM-5.3 และ Flash) และหน้า Usage Stats ที่แสดงโควต้าที่เหลือ จำตำแหน่งทั้งสองไว้เพราะจะใช้บ่อย (ดูภาพที่ หน้าจอ ZCode)
✅ ผ่านเมื่อ

เห็นชื่อบัญชีของคุณ เลือกโมเดล Flash ได้ และเห็นโควต้าคงเหลือ

3

เชื่อมเครื่องกับบัญชี Cloudflare

🎯 ทำขั้นนี้เพื่ออะไร

wrangler คือโปรแกรมของ Cloudflare ที่สั่งงานด้วยการพิมพ์คำสั่งใน terminal คำสั่ง login จะอนุญาตให้เครื่องนี้ deploy (นำแอปขึ้นออนไลน์) ไปยังบัญชีของคุณ สิทธิ์นี้ถูกเก็บไว้บนเครื่อง จึงต้อง logout ตอนเลิกเรียน (PART D)

ก่อนรันคำสั่ง ให้เปิดเบราว์เซอร์ไปที่ dash.cloudflare.com แล้วล็อกอินด้วยบัญชีของคุณ (ถ้ามีบัญชีคนอื่นค้างอยู่ ให้ออกจากระบบก่อน) จากนั้นพิมพ์คำสั่งนี้ใน Git Bash:

npx wrangler login
  1. ถ้า npx ถามว่าจะติดตั้ง wrangler ไหม ให้พิมพ์ y แล้วกด Enter
  2. เบราว์เซอร์จะเปิดหน้า Cloudflare ขึ้นมาเอง ตรวจว่าอีเมลที่แสดงเป็นของคุณ แล้วกด Allow
  3. กลับมาที่ Git Bash จะมีข้อความว่า login สำเร็จ จากนั้นรันคำสั่งข้างล่างเพื่อตรวจว่าเครื่องเชื่อมกับบัญชีไหน
npx wrangler whoami
✅ ผ่านเมื่อ

คำสั่ง whoami แสดงอีเมลของคุณ — ถ้าเป็นอีเมลคนอื่น ห้าม deploy ให้รัน npx wrangler logout แล้ว login ใหม่
