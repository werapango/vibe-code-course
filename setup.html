PART A — เตรียมเครื่อง Lab (ผู้สอน / IT)

📄 เอกสารฉบับเต็มสำหรับผู้ดูแลห้อง

คำสั่งติดตั้งแบบเงียบ (winget / msiexec), รายการเครือข่าย, สคริปต์ตรวจรับ check-lab.ps1 และใบตรวจรับรายเครื่องสำหรับพิมพ์ อยู่ที่ เอกสารติดตั้งซอฟต์แวร์ห้อง Lab

ผู้เรียนไม่ต้องทำส่วนนี้ — เป็นสเปกสำหรับผู้ดูแลห้อง Lab

A1. ซอฟต์แวร์ที่ต้องติดตั้งทุกเครื่อง

ซอฟต์แวร์เวอร์ชันใช้ทำอะไรหมายเหตุการติดตั้ง
Node.jsLTS (22 ขึ้นไป)รัน npm และ npx wranglerตัวติดตั้ง .msi จาก nodejs.org · ค่าเริ่มต้นทั้งหมด (รวม Add to PATH)
Git for Windowsล่าสุดcheckpoint ทุก task + ได้ Git Bashค่าเริ่มต้นทั้งหมด · คงตัวเลือก “Git Bash Here”
VS Codeล่าสุดอ่านโค้ดและ diffติ๊ก “Add to PATH” และ “Open with Code”
ZCodeล่าสุดAI coding agentจากหน้าดาวน์โหลดของ Z.ai · ไม่ต้องล็อกอิน (ผู้เรียนล็อกอินบัญชีตัวเองวันอบรม)
เบราว์เซอร์ (Chrome / Edge)ล่าสุดทดสอบแอป + F12 ดู cookie · สมัคร/ล็อกอินบริการ–

ไม่ต้องติดตั้ง wrangler แยก — แต่ละโปรเจกต์ติดตั้งเองใน node_modules และเรียกผ่าน npx · curl มีใน Windows 10/11 อยู่แล้ว · ผู้เรียนไม่ต้องมีสิทธิ์ administrator ทุกคำสั่งในหลักสูตรติดตั้งลงโฟลเดอร์โปรเจกต์หรือโฟลเดอร์ผู้ใช้

A3. ทดสอบเครื่องต้นแบบ 1 เครื่อง

🎯 เจตนา

ยืนยันว่า image ของห้องใช้ได้จริงก่อนโคลนไปทุกเครื่อง — ทำด้วยบัญชีทดสอบของผู้สอน (ไม่ใช่บัญชีผู้เรียน)

เปิด Git Bash แล้วรันทีละบรรทัด:

node -v
git --version
code --version
npm create cloudflare@latest my-app -- --template=werapango/workers-app-starter --no-deploy --no-git --no-agents
cd my-app
npm run dev

เปิด http://localhost:8787 ต้องเห็นหน้า "แอปของฉัน" และ /api/health ตอบ "ok": true (ช่วงนี้ db เป็น "no-binding" เพราะยังไม่สร้างฐานข้อมูล — ปกติ) → Ctrl+C → แล้วทดสอบ login และ deploy ด้วยบัญชีทดสอบ:

npx wrangler login
npx wrangler deploy
npx wrangler delete
npx wrangler logout
✅ ผ่านเมื่อ

ทุกคำสั่งทำงาน · เปิด URL workers.dev ได้ · login ไม่ค้างหลังกด Allow · logout แล้ว npx wrangler whoami บอกว่ายังไม่ได้ล็อกอิน

⚡ ทางลัด: อุ่น npm cache

การรันคำสั่ง C3 ข้างบนหนึ่งครั้งบนเครื่องต้นแบบ ทำให้แพ็กเกจถูกเก็บใน npm cache ของ image วันอบรมทั้งห้องจะติดตั้งเร็วขึ้นและไม่แย่งแบนด์วิดท์พร้อมกัน (ถ้าเครื่องใช้ระบบคืนค่าอัตโนมัติ ให้ทำก่อนบันทึก image)

⚠ ถ้าเครื่องคืนค่าอัตโนมัติเมื่อรีสตาร์ท (Deep Freeze ฯลฯ)

งานของผู้เรียนจะหายเมื่อรีสตาร์ท — แจ้งผู้เรียนว่าห้ามรีสตาร์ทเครื่องระหว่างวัน หรือกำหนดโฟลเดอร์/ไดรฟ์ที่ไม่ถูกคืนค่าให้เก็บงาน (โค้ดที่ deploy แล้วยังอยู่บน Cloudflare แต่ซอร์สโค้ดอยู่บนเครื่อง)

PART B — สมัครบัญชี (ผู้เรียน)

ทำผ่านเว็บเบราว์เซอร์อย่างเดียว ไม่ต้องติดตั้งอะไร — ทำล่วงหน้าจากมือถือได้ เพื่อประหยัดเวลาช่วงเช้า ถ้ายังไม่ได้ทำ ทำบนเครื่อง Lab ตอน 09:00

B1. บัญชี Z.ai

🎯 เจตนา

รับโควต้าฟรีของ ZCode (GLM-5.3 ~3M + Flash ~5M token) — บัญชีเป็นของคุณ ส่วนโปรแกรม ZCode ติดตั้งไว้บนเครื่อง Lab แล้ว

  1. สมัครบัญชีที่เว็บ z.ai (อีเมลหรือ Google)
  2. ยืนยันอีเมล (ถ้ามี)
✅ ผ่านเมื่อ

ล็อกอินหน้าเว็บ z.ai ได้

🪙 อย่าเพิ่งใช้โควต้า

ไม่ต้องลองสั่งงานล่วงหน้า เก็บโควต้าไว้ใช้วันอบรม (ทั้งวันใช้ประมาณ 0.4–0.7M)

B2. บัญชี Cloudflare (Free)

บริการที่ใช้ โควตาฟรี และบริการที่ไม่ต้องกด: Cloudflare ที่ใช้ในหลักสูตร

🎯 เจตนา

บัญชีที่แอปของคุณจะไปอยู่ — สมัครไว้ก่อนเพื่อไม่ต้องรอสมัครพร้อมกันทั้งห้อง และอีเมลยืนยันมีเวลามาถึง

  1. เปิด dash.cloudflare.com/sign-up → สมัครด้วยอีเมล
  2. ยืนยันอีเมล (คลิกลิงก์ในอีเมลที่ Cloudflare ส่งมา — ถ้ายังไม่ยืนยัน บางคำสั่งจะใช้ไม่ได้)
  3. ถ้ามีหน้าให้เลือกแผน เลือก Free · ถ้าถามว่าจะเพิ่มเว็บไซต์/โดเมน ให้ข้าม (เราใช้ workers.dev ฟรี ไม่ต้องมีโดเมน)
⚠ ถ้าหน้าจอขอบัตรเครดิต

หยุด ไม่ต้องกรอก กลับไปหน้า dashboard หลัก — การสมัครบัญชีและการใช้ Workers/D1 ไม่ต้องใช้บัตร

✅ ผ่านเมื่อ

เข้าหน้า dashboard ของ Cloudflare ได้ และยืนยันอีเมลแล้ว — จำอีเมลและรหัสผ่านไว้ใช้ล็อกอินบนเครื่อง Lab

B3. บัญชี Gemini หรือ ChatGPT (เลือกอย่างใดอย่างหนึ่ง)

🎯 เจตนา

ใช้ใน Lab 2 ช่วยร่างเอกสารความต้องการ (SRS) และการออกแบบ ผ่านหน้าเว็บ — ฟรี ไม่ใช้โควต้า ZCode เก็บโควต้า ZCode ไว้เขียนโค้ดตอนบ่าย

  • Gemini: gemini.google.com ล็อกอินด้วยบัญชี Google
  • ChatGPT: chatgpt.com สมัครด้วยอีเมลหรือบัญชี Google
⚠ ใช้แผนฟรีเท่านั้น

ไม่ต้องสมัครแผนเสียเงินหรือกรอกบัตร · ห้ามใส่ข้อมูลส่วนตัวหรือข้อมูลจริงของหน่วยงานลงใน prompt — วันนี้ใช้แค่โจทย์สมมติของหลักสูตร

✅ ผ่านเมื่อ

เปิดหน้าแชตและพิมพ์ข้อความได้ — จำรหัสผ่านไว้ล็อกอินบนเครื่อง Lab

PART C — ตั้งค่าบนเครื่อง Lab เช้าวันอบรม (ผู้เรียน)

ทำช่วง 09:00–09:20 ผู้สอนจะเดินตรวจทีละเครื่อง

1

เปิด Git Bash

🎯 เจตนา

terminal คือหน้าต่างที่เราพิมพ์คำสั่ง Cloudflare เองตลอดวัน Git Bash พิมพ์ได้ตรงกับเอกสาร lab ทุกตัวอักษร

กด Start → พิมพ์ Git Bash → Enter (หัวบรรทัดมีคำว่า MINGW64) แล้วตรวจเครื่องมือ:

node -v
git --version
✅ ผ่านเมื่อ

Node ได้ v22 ขึ้นไป และ Git ขึ้นเลขเวอร์ชัน (ถ้าไม่ขึ้น แจ้งผู้สอน — เป็นปัญหาของเครื่อง ไม่ใช่ของคุณ)

2

ล็อกอิน ZCode

🎯 เจตนา

ผูก ZCode บนเครื่องนี้กับบัญชี Z.ai ของคุณ เพื่อใช้โควต้าของตัวเอง

  1. เปิด ZCode → ล็อกอินด้วยบัญชี Z.ai ของคุณ (ถ้าเห็นบัญชีคนอื่นค้างอยู่ ให้ออกจากระบบก่อน)
  2. หา ที่เลือกโมเดล (ต้องเห็นทั้ง GLM-5.3 และ Flash) และ หน้าดูโควต้าที่เหลือ — จำตำแหน่งไว้
✅ ผ่านเมื่อ

เห็นชื่อบัญชีของคุณ เลือกโมเดล Flash ได้ และเห็นโควต้าคงเหลือ

3

เชื่อมเครื่องกับบัญชี Cloudflare

🎯 เจตนา

wrangler คือเครื่องมือ command line ของ Cloudflare — login ให้สิทธิ์เครื่องนี้ deploy ไปยังบัญชีของคุณ สิทธิ์นี้ถูกเก็บไว้บนเครื่อง จึงต้อง logout ตอนเลิกเรียน (PART D)

ก่อนรันคำสั่ง ล็อกอิน dash.cloudflare.com ในเบราว์เซอร์ด้วยบัญชีของคุณ (ถ้ามีบัญชีคนอื่นค้างอยู่ ให้ออกจากระบบก่อน)

npx wrangler login
  1. ถ้า npx ถามว่าจะติดตั้ง wrangler ไหม → พิมพ์ y
  2. เบราว์เซอร์เปิดหน้า Cloudflare → ตรวจว่าเป็นอีเมลของคุณ → กด Allow
  3. กลับมาที่ Git Bash จะขึ้นว่า login สำเร็จ
npx wrangler whoami
✅ ผ่านเมื่อ

whoami แสดงอีเมลของคุณ — ถ้าเป็นอีเมลคนอื่น ห้าม deploy ให้ npx wrangler logout แล้ว login ใหม่

📖 เรื่อง subdomain workers.dev

บัญชีใหม่จะถูกให้ตั้งชื่อ subdomain ตอน deploy ครั้งแรกใน Lab 1 (เช่น somchai-dev → URL เป็น https://my-app.somchai-dev.workers.dev) เตรียมชื่อภาษาอังกฤษตัวเล็กสั้น ๆ ไว้ 1 ชื่อ

เช็กลิสต์ก่อนเริ่ม Lab 1

  • Git Bash เปิดได้ · node -v ได้ v22 ขึ้นไป
  • ZCode ล็อกอินด้วยบัญชีของฉัน เห็นโมเดล Flash / GLM-5.3 และโควต้า
  • Cloudflare ยืนยันอีเมลแล้ว และไม่ได้ผูกบัตร
  • npx wrangler whoami แสดงอีเมลของฉัน
  • ล็อกอิน Gemini หรือ ChatGPT ในเบราว์เซอร์ได้ (ใช้ใน Lab 2)
  • เตรียมชื่อ subdomain workers.dev ไว้แล้ว

การตั้งชื่อ/อีเมลให้ Git ทำใน Lab 1 หลัง git init แบบเฉพาะโปรเจกต์ (ไม่ใช้ --global) เพื่อไม่ให้ชื่อของคุณติดอยู่กับเครื่องส่วนกลาง
